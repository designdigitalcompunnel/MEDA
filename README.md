# MEDA Website Demo

Open `index.html` in a browser for the homepage. The Public Documents link opens `documents.html`. Keep the `assets` directory alongside both pages. The ZIP contains the site, videos, photos, typefaces, and example PDFs. A local web server is optional.

## What the demo covers

- A homepage introducing the Moffat Economic Development Authority, its board, and its economic priorities.
- A Public Documents page with minutes by year, governing documents, and a filterable archive.
- A shared five-link header, document search, light and dark themes, keyboard controls, and pause buttons for the hero video and motion.

## Content for a production launch

The archive entries and dates are clearly marked examples. Replace the example files and metadata in `assets/records.js` with approved MEDA PDFs and actual meeting dates. Update featured-document links and year shortcuts on the two pages when replacing the examples. The contact section points to the published board contact. Use MEDA's dedicated organizational inbox when it becomes available.

Primary copy is in the two HTML files. The palette and media styling are in `assets/meda.css`. The source and licensing information is in [Media credits](MEDIA_CREDITS.md).
